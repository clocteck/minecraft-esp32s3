# Upstream

This port vendors [ClassiCube](https://github.com/ClassiCube/ClassiCube) under
`upstream/ClassiCube` at commit
`bb706fd05ad6c338e68a17b4f2db45ef3a21663a` (2026-08-14).

The upstream code is BSD-3-Clause licensed. The vendored snapshot contains
local ESP32-S3 platform, renderer, and memory-management changes; the dynamic
module host adapter lives in `src/main`.

Upstream documentation not needed by this port has been trimmed. The complete
original documentation remains available in the
[ClassiCube repository](https://github.com/ClassiCube/ClassiCube).
