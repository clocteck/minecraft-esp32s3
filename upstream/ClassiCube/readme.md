本目录保存本项目编译所需的 [ClassiCube](https://github.com/ClassiCube/ClassiCube) 源码快照，基于提交 `bb706fd05ad6c338e68a17b4f2db45ef3a21663a`，并包含 ESP32-S3 平台、软件渲染和内存管理相关修改。

---

This directory contains the vendored [ClassiCube](https://github.com/ClassiCube/ClassiCube) source snapshot used by this project. It is based on commit `bb706fd05ad6c338e68a17b4f2db45ef3a21663a` and includes local ESP32-S3 platform, software-rendering, and memory-management changes.

See the repository [README](../../README.md) for project details, hardware requirements, installation, and build instructions. The complete upstream documentation remains available in the [official ClassiCube repository](https://github.com/ClassiCube/ClassiCube).

Upstream ClassiCube code is licensed under BSD-3-Clause. See [license.txt](license.txt) and [UPSTREAM.md](../../UPSTREAM.md).
